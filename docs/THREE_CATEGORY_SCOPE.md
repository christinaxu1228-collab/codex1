# SHEIN Excel 第一版：三个类目

用户确认仅需这三种：
- 女士两件套 (95-1780)
- 女士短连衣裙 (67-1727)
- 女士连体裤 (154-1860) —— 用户口头称“紧身衣”；如产品实际是 bodysuit（连体紧身衣），须再次核实与后台正确类目匹配，不能仅凭名称强行映射。

## 原始模板核验
- 第一份模板：两件套
- 第二份模板：两件套 + 短连衣裙
- 最新第三份文件“批量添加商品模板 (2).xlsx”：同时含这三个类目。
- 最新文件还有“操作指引”、“有效属性值”、“有效品牌列表”、“有效产地列表”、“尺寸表模板”及 MainAttribute 相关工作表。
- 三个商品类目工作表数据从第 7 行开始；前 6 行模板原样保留。
- 不应将原始上传文件直接提交到公开 GitHub，应该通过后台上传模板进行映射。
- 用户主要诉求：Codex 做可视化批量数据导入、每类目映射、模板导出、预检，再由 SHEIN 后台上传和草稿批量发布；目前无需开放平台授权。

## 工程验收
1. Web UI 可上传一个含三类目的官方 XLSX 模板，自动识别以上工作表名称。
2. 支持导入商品清单，按类别填写对应工作表从第7行开始，保留其它辅助工作表、数据验证和单元格样式。
3. SKU 唯一性、SPU 分组、颜色/尺码、图片、供货价、库存等依据模板实际字段校验。
4. 预览每类目数量、错误行、导出统计。
5. 导出后保持完整 XLSX 结构并回读确认，与 SHEIN 后台当前上传大小限制一致。
6. 上传成功进入草稿，不得宣传为自动完成上架。
7. 待实际发布确认前，保持纯本地 Excel 导出，无店铺凭据、无真实上传调用。
